# Concept Image Prompts

统一风格基线：

- 面向企业内部演示
- 现代信息图、干净、克制、结构清晰
- 非学术论文海报风，不用复杂公式，不用密集小字
- 16:9 横版构图，适合 Slidev 全页展示
- 配色理性、科技感但不过冷，建议蓝绿灰体系，少量橙色做强调
- 图形语言以流程箭头、分层卡片、模块框、状态流为主
- 文字以中文为主，仅保留必要英文术语
- 留足空白，避免“塞满一页”

## 1. `llm-next-token-prediction.png`

主题：`next-token prediction`

Prompt：

> 设计一张面向企业内部演示的现代信息图，主题是“大语言模型的基本机制：next-token prediction”。画面为 16:9 横版，风格统一、简洁、现代、信息图感强，不要学术海报风，不要复杂公式。核心内容是用非常直观的方式解释：模型读取前文上下文，然后预测下一个最可能出现的 token，再不断重复这个过程，最终生成整段文本。画面采用从左到右的流程结构：左侧是“输入上下文”，中间是“预测下一个 token”，右侧是“不断重复，生成完整回答”。上下文区域可以用简洁中文词组示意，例如“我 / 今天 / 想 / 讲 / AI / Agent”，下一个 token 区域突出一个候选词元，例如“的”或“是什么”，并用几个较淡的备选 token 表现“概率选择”，但不要出现数学公式。右下角用一块简洁提示区说明：LLM 擅长语言生成与局部判断，但天然不等于执行系统。整体视觉要像高质量企业战略演示中的解释图，而不是教材插图。

图里必须出现的文字元素：

- `LLM 的基本机制`
- `next-token prediction`
- `输入上下文`
- `预测下一个 token`
- `不断重复`
- `生成完整回答`
- `擅长生成与判断，不天然擅长执行与控制`

避免出现的元素：

- 大段公式
- transformer 结构细节图
- 注意力矩阵、张量、神经网络层堆叠
- 论文海报排版
- 过多英文长句
- 卡通机器人形象

## 2. `react-agent-loop.png`

主题：`ReAct / agent loop`

Prompt：

> 设计一张面向企业内部演示的现代信息图，主题是“ReAct / agent loop”。画面为 16:9 横版，现代、清晰、结构感强，突出 agent 的工作闭环，不要学术风，不要密集公式。核心内容是展示一个围绕任务目标持续运行的循环：用户目标进入系统后，Agent 先进行 `Reason（判断）`，再进行 `Act（执行动作）`，然后 `Observe（读取结果）`，再回到下一轮判断，直到“完成任务”或“停止”。建议用一个大号环形或椭圆循环结构放在画面中央，左侧单独放“用户目标”，右侧放“完成任务”。在 `Act` 节点周围用简洁小图标表示 agent 可调用的外部能力，例如：终端、文件、浏览器、API。强调这不是单纯的思考流程，而是“判断 + 执行 + 观察”的真实运行闭环。底部加一条简洁说明：当 `Act` 能真正调用工具和环境时，Agent 就从“回答模式”升级成“执行系统”。整体风格要像企业产品架构说明图，专业但易懂。

图里必须出现的文字元素：

- `ReAct`
- `Agent Loop`
- `用户目标`
- `Reason（判断）`
- `Act（执行动作）`
- `Observe（读取结果）`
- `继续下一轮`
- `完成任务`
- `从回答模式到执行系统`

避免出现的元素：

- 论文式大段解释文字
- 复杂代码片段
- 过多节点导致图形拥挤
- 拟人化大脑、夸张机器人插画
- 深奥算法符号
- 花哨 3D 效果

## 3. `agent-capability-stack.png`

主题：`Agent capability stack`

Prompt：

> 设计一张面向企业内部演示的现代分层信息图，主题是“Agent capability stack”。画面为 16:9 横版，视觉风格统一、现代、清楚、适合讲解，不要学术海报风。核心目的是让非技术同事理解：Agent 不是“装几个插件”，而是一套分层能力栈。画面采用自下而上的分层结构，每一层都是宽卡片或平台式结构，层次分明。最底层是 `Runtime / Harness（运行时 / 执行框架）`，往上是 `Tools（工具）`，再上是 `Retrieval / RAG（检索增强）` 与 `MCP`，再上是 `Skills`、`Memory`、`Subagents`，最上层是面向用户任务的 `Agent`。右侧可以用一列简洁标签说明每层解决什么问题，例如“让系统跑起来”“让 Agent 真正做事”“让 Agent 看见信息”“让能力可复用”“让任务可分工”。整体图要像企业内部技术战略分层图，逻辑清楚，留白充足，重点强调“分层能力栈”而不是“一堆零散插件”。

图里必须出现的文字元素：

- `Agent capability stack`
- `Agent`
- `Runtime / Harness（运行时 / 执行框架）`
- `Tools（工具）`
- `Retrieval / RAG（检索增强）`
- `MCP`
- `Skills`
- `Memory`
- `Subagents`
- `不是一堆插件，而是一套能力栈`

避免出现的元素：

- 太多小图标堆满整页
- 每层写大段说明文字
- 学术框架对比表
- 复杂拓扑网络图
- 五颜六色过度装饰
- 品牌 logo 墙

## 4. `prompt-context-harness-evolution.png`

主题：`Prompt -> Context -> Harness`

Prompt：

> 设计一张面向企业内部演示的现代信息图，主题是“Prompt -> Context -> Harness 的工程重心演进”。画面为 16:9 横版，风格统一、现代、信息图感强，不要论文海报风。核心目标是解释：AI 工程重心为什么会从 `Prompt Engineering` 演进到 `Context Engineering`，再演进到 `Harness Engineering`。画面采用从左到右的三阶段演进结构，每一阶段是一张大卡片，分别写 `Prompt Engineering（提示词工程）`、`Context Engineering（上下文工程）`、`Harness Engineering（执行框架工程）`。每张卡片下方只放一句非常清楚的问题定义：Prompt 阶段强调“怎么把任务说清楚”；Context 阶段强调“每一步该给模型看什么”；Harness 阶段强调“怎么让整套系统稳定把任务做完”。三张卡片之间不要只是普通箭头，要用“任务复杂度上升”“多工具、多步骤、长任务”“真实执行与反馈闭环”这类中间驱动因素来连接，明确表达这是问题升级导致的工程重心外移，而不是流行词替换。整体要像企业演讲里解释技术演进逻辑的高质量战略图，简洁、强逻辑、强层次。

图里必须出现的文字元素：

- `Prompt Engineering（提示词工程）`
- `Context Engineering（上下文工程）`
- `Harness Engineering（执行框架工程）`
- `怎么把任务说清楚`
- `每一步该给模型看什么`
- `怎么让整套系统稳定把任务做完`
- `任务复杂度上升`
- `多工具、多步骤、长任务`
- `真实执行与反馈闭环`

避免出现的元素：

- 简单无脑三段箭头
- 空泛趋势词云
- 学术论文时间线
- 太多年份与人名
- 复杂数学符号
- 过度未来感科幻插画

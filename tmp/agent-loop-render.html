Agent loop：从回答问题，到推进任务

ReAct 是经典策略：Reason / Act / Observe 交错发生；Agent loop 是外层控制循环，必须有停止条件和最终输出。
用户目标“帮我完成这件事”
Reason判断下一步
是否需要工具
Act发起 tool call
或执行动作
Observe读取工具结果
环境反馈
判断是否完成目标达成 / 出错 / 需确认
Final answer把结果交还给用户
动作请求
证据返回
未完成：继续循环
完成：退出循环
图上一定要有出口：真实 agent 不应该无限循环。通常会因为完成目标、达到最大轮数、遇到错误、需要人类确认，或者生成最终答案而停止。
